# Moonstone Heritage Stamp Trail

A mobile-friendly static website for a self-guided heritage trail around Moonstone Lane Estate.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish on GitHub Pages

1. Upload the contents of this folder to a GitHub repository.
2. In **Settings → Pages**, select **Deploy from a branch**.
3. Select the branch containing these files and the `/ (root)` folder.
4. Save, then use these URL patterns in the four station QR codes:
   - `https://YOUR-NAME.github.io/YOUR-REPO/?station=food`
   - `https://YOUR-NAME.github.io/YOUR-REPO/?station=temple`
   - `https://YOUR-NAME.github.io/YOUR-REPO/?station=keramat`
   - `https://YOUR-NAME.github.io/YOUR-REPO/?station=factory`

No build step or external framework is required. Progress is stored locally in the visitor's browser.

## Before public use

- Replace all image placeholders with approved images.
- Verify stall names, menus and opening hours.
- Confirm historical wording and site-access guidance with local stakeholders.
- Test QR codes on iOS and Android using the final GitHub Pages URL.
